How it works

🧠

Read activations

Open weights give us residual-stream hidden states. We compute Δ between task-only and task+output activations at a middle layer.

📐

Linear probe

A lightweight logistic regression trained on Δ vectors distinguishes clean outputs from injected ones. Trains on CPU in seconds.

🛡️

Block or steer

Score above threshold → block the action. Or apply a steering vector via forward hook to pull the model back to the user's task.

🌐

Layered defence

Anchor guards the model's intent. Pipelock (unmodified) guards the network. Each stops attacks the other misses.
