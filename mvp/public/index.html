03 · How it works

From tool output to a blocked email

For each tool output, Anchor compares the model's hidden state at the start of its reply with and without the page. A linear probe scores that difference. A high score taints the run, and every later side-effecting action is blocked.

user task→fetch_page→tool output→ hidden state @ reply start→Δ vs task alone→ linear probe→score ≥ threshold → run tainted→send_email blocked

Data
SQuAD paragraphs (CC BY-SA 4.0) with inserted injections and length-matched benign sentences, plus hard negatives. Pages come as prose or as JSON tool responses; clean pages include benign non-English sentences. Split by document 70/15/15; train, validation and test use different injection templates. Hindi/Hinglish injections are held out from training and tuning (Devanagari appears in training only as benign text). External check: InjecAgent (MIT), never used for training or tuning.
